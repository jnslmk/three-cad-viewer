## Overview

three-cad-viewer is a Three.js-based CAD viewer component used by vscode-ocp-cad-viewer. It provides the 3D visualization, navigation controls, measurement tools, and UI components.

## Commands

```bash
# Install dependencies
npm install

# Build production bundle (outputs to dist/)
npm run build

# Development mode with watch
npm run start

# Development mode with sourcemaps
npm run debug
```

## Architecture

- `src/` - Source JavaScript modules
  - `cad_tools/` - Measurement and selection tools (distance, properties, picker)
  - `controls/` - Camera and navigation controls
  - `viewer.js` - Main viewer class
  - `display.js` - Display management and UI
  - `toolbar.js` - Toolbar component
- `dist/` - Built output (gitignored, generated by rollup)
  - `three-cad-viewer.esm.js` - ES module bundle
  - `three-cad-viewer.css` - Styles

## Build Workflow with vscode-ocp-cad-viewer

The built `dist/` files need to be copied to vscode-ocp-cad-viewer for testing:

```bash
# After making changes and building:
npm run build

# Copy to vscode-ocp-cad-viewer (adjust paths as needed)
cp dist/three-cad-viewer.esm.js ../vscode-ocp-cad-viewer/ocp_vscode/static/js/
cp dist/three-cad-viewer.css ../vscode-ocp-cad-viewer/ocp_vscode/static/css/
```

The JS/CSS files in vscode-ocp-cad-viewer are gitignored since they come from this package. For production, vscode-ocp-cad-viewer installs three-cad-viewer from npm.

## Adding New Tools

Tools live in `src/cad_tools/`. To add a new tool:

1. Create a new file (e.g., `picker.js`) with your tool class
2. Export from the file with `enableContext()`, `disableContext()`, `handleSelection()`, `handleResponse()`, `update()`, `dispose()` methods
3. Import and integrate in `tools.js`:
   - Add to `ToolTypes` enum
   - Instantiate in constructor
   - Add cases in `enable()`, `_disable()`, `handleSelectedObj()`, `handleResponse()`, `update()`, `dispose()`
